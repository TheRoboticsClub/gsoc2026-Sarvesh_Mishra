## Community Bonding Period

I am incredibly excited to be working with the JdeRobot community on the Robotics-Academy project for Google Summer of Code 2026! My accepted project is titled:

**VisualCircuit: Improving Functionality and Block Library**

Google Summer of Code kicks off with a Community Bonding phase. This is a dedicated period for contributors to get to know their mentors, engage with the community, and deepen their technical understanding of both the organization and the project before coding officially begins.

### Objectives for this week
- Set up and deploy my project blog using Jekyll and GitHub Pages.
- Interact with my mentors and become actively involved in the community channels.
- Test and run various Robotics Academy exercises utilizing VisualCircuit to better understand the current architecture.

### Progress so far
This week, I successfully built and deployed the blog you are reading right now! I also introduced myself to my mentors, joined the community Slack, and familiarized myself with the general workflow at JdeRobot. We have our first official team meeting scheduled for next week, where we will go over logistics, finalize timelines, and lock in the technical roadmap for the project.

![Meeting Image](/assets/img/posts/week1_image.png)

I also had the wonderful opportunity to attend the official Google Summer of Code 2026 Contributor Welcome Session hosted by Google. It was a great way to learn more about the expectations of the program and what lies ahead for the summer.

Stay tuned for weekly updates as I dive deeper into the codebase in the coming weeks!
